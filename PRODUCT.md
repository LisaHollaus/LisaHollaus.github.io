# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary audiences are:
- Recruiters and hiring managers evaluating Lisa-Maria Hollaus for roles in data science, software development, AI, or related fields.
- Potential freelance clients evaluating Lisa for project-based work.

## Product Purpose

Present Lisa-Maria Hollaus's profile, experience, skills, education, and project work, and help visitors evaluate whether to hire or contact her.

## Positioning

A personal portfolio that combines a data science and informatics education with unconventional career experience in confectionery, agriculture, UX, publishing, AI tools, and independent work.

## Operating Context

The portfolio is a public static website for desktop and mobile visitors. It provides project previews, downloadable evidence such as a CV and bachelor thesis, external GitHub and professional profile links, and a contact section.

## Capabilities and Constraints

- Static HTML/CSS/JavaScript portfolio hosted on GitHub Pages.
- Existing content, links, downloadable documents, profile assets, and project evidence must remain factual and intact.
- The site must continue to work across desktop and mobile screen sizes.
- No invented testimonials, customers, metrics, project outcomes, licenses, or deployment claims.

## Brand Commitments

- The portfolio identity is Lisa-Maria Hollaus.
- Voice is personal, clear, and grounded in real learning and career experience.
- Existing profile copy and practical, evidence-led presentation are part of the incumbent portfolio.

## Evidence on Hand

- Profile and biography: `index.html`
- CV: `docs/CV-2026_en.pdf`
- Bachelor thesis: `docs/bachelor-thesis_Hollaus.pdf`
- Project descriptions and external GitHub links: `index.html`
- Profile and project imagery: `images/`
- Professional and social links: `index.html`

## Product Principles

- Make Lisa's range understandable quickly.
- Let real experience and evidence support claims.
- Preserve the direct path from evaluation to contact or download.
- Keep the portfolio practical and credible rather than promotional.
